# NEO MIDGARD — Android Saga

เกม RPG โลกหุ่นยนต์แอนดรอยด์ในดินแดนตำนานนอร์ส เล่นบนเบราว์เซอร์ ระบบเรียบง่ายแบบ MMORPG คลาสสิก
ตัวละครทุกตัวเป็นแอนดรอยด์ (วิเซอร์เรืองแสงแทนดวงตา) มอนสเตอร์เป็นเครื่องจักร เมืองเป็นฐานไซไฟ เขียนด้วย HTML5 Canvas + JavaScript ล้วน
ไม่ต้องติดตั้งหรือ build อะไรเลย • ภาพวาดจาก ChatGPT อยู่ใน `assets/` (WebP) ตัวละครเคลื่อนไหวแบบวาดทีละเฟรม 8 ทิศ • เสียงสังเคราะห์ด้วยโค้ด

## วิธีเล่น

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์ง่าย ๆ:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

### รองรับทุกอุปกรณ์

- **คอมพิวเตอร์** — เมาส์ + คีย์ลัด
- **แท็บเล็ต** — ปุ่มใหญ่ขึ้น ปุ่มลัด 48px เมนูกลางจอ รองรับทั้งแนวตั้ง/แนวนอน
- **มือถือ** — แตะเพื่อเดิน/โจมตี, ถ่างสองนิ้วเพื่อซูม, แตะค้างปุ่มลัดเพื่อลบ, เลย์เอาต์แนวนอนแยกเฉพาะ, โหมดเต็มจอ (เมนูตั้งค่า)

### ระบบบอท (Auto Hunt)

กดปุ่ม **AUTO** (หรือ `B`) เพื่อปล่อยบอทล่ามอนสเตอร์ในแผนที่ปัจจุบัน:

- เลือกเป้าหมายเอง (ตัวที่กำลังตีเราก่อน) และเดินหามอนสเตอร์เมื่อไม่มีเป้าหมาย
- ใช้สกิลโจมตี / บัฟ / ฮีล / เรียกหมาป่า / วางกับดัก ตามบทบาทของสกิล (เลือกสกิลที่ให้ใช้ได้)
- กินยา HP/SP ตามเปอร์เซ็นต์ที่ตั้ง, นั่งพักเมื่อ HP/SP ต่ำ, เก็บของ
- หลีกเลี่ยง MVP, กลับเมืองอัตโนมัติเมื่อยาหมดและ HP วิกฤต, หยุดเมื่อตัวละครตาย
- บอทปลดล็อกเมื่ออัปเกรดคลาสแรก (ช่วง Novice ให้เล่นเอง)
- **ทำงานต่อแม้สลับแท็บหรือสลับแอป** (จำลองย้อนหลังสูงสุด 10 นาที) พร้อมสรุปผลเมื่อกลับมา
- แสดงสถิติ: เวลา, จำนวนที่ล่าได้, EXP ที่ได้, EXP/นาที

| Wildhunter (นักล่าแห่งป่า) | ธนู + สัตว์คู่ใจ | DEX / AGI | Eagle Eye, Piercing Arrow, Wolf Companion, Blast Trap |
| Völva (นักพยากรณ์แห่งแสง) | ฮีล บัฟ ปราบอมตะ | INT / VIT | Sanctuary, Light of Freyja, Blessing of Odin, Holy Spear |
| Loki's Trickster (นักลวงแห่งโลกิ) | ว่องไว คริติคอล | AGI / LUK | Shadow Step, Backstab, Smoke Veil, Venom Blade |
| Berserker (นักรบคลั่ง) | แลก HP เป็นพลัง | STR / AGI | Wolf Blood, Rage Strike, Blood Frenzy, Howl |

- **สเตตัส** STR / AGI / VIT / INT / DEX / LUK, Base Lv สูงสุด 99
- **ความชำนาญ (ยิ่งเล่นยิ่งเก่ง)**: สกิลกดใช้แต่ละอันและการโจมตีปกติเก็บความชำนาญจากการใช้ ได้สูงสุด Lv 10 (สกิลแรงขึ้น 3%/Lv, โจมตีปกติ 2%/Lv) ดูได้ในหน้าสกิล
- **ต้นไม้พาสซีฟ (แบบ Path of Exile)** กด `P` — 157 จุดใน 6 แฉก (ป้อมปราการ/คลั่ง/เงา/นักล่า/รูน/พยากรณ์) ได้ 1 แต้มต่อ Base Level เปิดจุดที่ติดกันต่อจากแกนกลาง มี Notable 30 จุด และ Keystone 6 จุดที่เปลี่ยนกติกา (เช่น Overclock, Blood Circuit, Mind over Matter) • คืนแต้มฟรีถึง Lv 15 จากนั้น 10z × Lv
- **สถานะผิดปกติ** มึน (Stun), ช้า (Slow), ไหม้ (Burn), พิษ (Poison)
- **ธาตุ** ไฟ/น้ำ/ดิน/ลม/ศักดิ์สิทธิ์/อมตะ ฯลฯ มีผลต่อความเสียหาย
- **ไอเทม** ชุดซ่อม (HP) เซลล์พลังงาน (SP) อาวุธพลังงาน 6 ประเภท เกราะ และ **ชิป** (ใส่ในช่อง `[ ]` ของอุปกรณ์ — ได้แน่นอนเมื่อล่ามอนชนิดนั้นครบ 50 ตัว, MVP ตัวแรก) ตีบวก +1 ถึง +10 (พลาดไม่แตก แค่เสียค่าบริการ)
- **มอนสเตอร์กลไก 18 ชนิด** (Slime Drone, Buzz Drone, Fenrir Unit, Tusk Tank, Draugr Husk ฯลฯ) + MVP 2 ตัว (Seraph Core, Kitsura EX)
- **แผนที่ 5 แห่ง**: ฐาน Neo Eldheim, Emerald Meadow, Mistlake Plains, Wolfwood Forest, Hel's Hollow (ถ้ำมืด)
- **NPC**: Bifrost Keeper (เซฟ/เทเลพอร์ต), Mimir AI (เปลี่ยนอาชีพ/รีเซ็ต), ร้านค้า 3 ร้าน, Brokk Forge-Bot (ตีบวก), Eir Repair Unit, Guard Unit Rolf (ไกด์/เควสต์), Storage Unit Kaia (คลังของ)
- **HUD แบบ Visor (มินิมอล)** เป็นค่าเริ่มต้น: วงแหวน HP/SP รอบรูป แถบลัดหกเหลี่ยม เส้น EXP ล่างจอ — สลับเป็นแบบคลาสสิกได้ในตั้งค่า (`css/visor.css`)
- **HUD พับได้**: ปุ่ม ▾ มุมแผงสถานะ/มินิแมพ/แชท/เมนู และปุ่ม ◉ หรือ `U` ซ่อน HUD ทั้งหมด
- **เควสต์เริ่มต้น 10 ขั้น** สอนระบบจนอัปเกรดคลาสแรก มีแถบติดตาม (แตะเพื่อเดินไปทำ) และเครื่องหมาย ! เหนือหัว NPC
- **งานล่าค่าหัวประจำวัน** (Base Lv 8+) ที่ Guard Unit Rolf: วันละ 3 งาน ล่ามอนที่เลเวลใกล้ตัว ได้ Volt + EXP ทำครบ 3 งานรับโบนัส • มอนดรอป Volt ทุกตัว
- **หุ่นฝึกซ้อม** 3 ตัวในเมือง (ไม่ตาย ตีกลับครั้งละ 1 แสดง DPS) • **คลังเก็บของ** 300 ช่อง (Storage Unit Kaia)
- **สมุดมอนสเตอร์**: สเตตัส ธาตุที่แพ้ ของดรอป แผนที่ที่พบ (ⓘ ในหน้านำทาง/กรอบเป้าหมาย)
- **ล็อกอิน**: บัญชีในเครื่อง (ไม่ต้องมีเซิร์ฟเวอร์) หรือบัญชีออนไลน์เมื่อตั้งค่า Supabase • เล่นแบบไม่ล็อกอินก็ได้
- บันทึกอัตโนมัติลง `localStorage` ของเบราว์เซอร์

## การเพิ่ม/แก้ไขสกิลและอาชีพ

สกิลทั้งหมดเป็น **ข้อมูล** ใน `js/data.js` (ไม่ต้องเขียนโค้ดเพิ่ม) ดูคำอธิบายรูปแบบที่หัวข้อ `SKILLS` ในไฟล์ ตัวอย่าง:

```js
meteor: { name: 'Meteor', max: 5, type: 'active', target: 'enemy', range: 9, icon: '#ff6020', glyph: '☄',
  sp: lv => 30 + 5 * lv, cast: lv => 2000, delay: 2000, fx: 'firebolt',
  dmg: { type: 'magic', element: 'fire', mult: lv => 1.5 + 0.3 * lv, area: 2, at: 'target',
         status: { kind: 'burn', chance: () => 50, dur: () => 4 } },
  desc: 'อุกกาบาตเพลิงตกใส่พื้นที่ 2 ช่อง' },
```

แล้วเพิ่ม `'meteor'` ในรายการ `skills` ของอาชีพที่ต้องการใน `JOBS`

## โหมดออนไลน์ (สมัครสมาชิก + เห็นผู้เล่นอื่น + แชท)

ใช้ [Supabase](https://supabase.com) เป็นเซิร์ฟเวอร์ (มีแพ็กเกจฟรี) ถ้ายังไม่ตั้งค่า เกมจะเล่นแบบออฟไลน์ตามปกติ

**สิ่งที่ได้:** สมัคร/ล็อกอินด้วยชื่อผู้ใช้ + รหัสผ่าน, เซฟตัวละครบนเซิร์ฟเวอร์ (เล่นต่อได้ทุกเครื่อง), เห็นผู้เล่นอื่นเดินในแผนที่เดียวกันแบบเรียลไทม์ (ชื่อ อาชีพ เลเวล ท่าทาง), แชทรวมทุกแผนที่ + บอลลูนข้อความเหนือหัว, จำนวนผู้เล่นในแผนที่ (👥)

### ขั้นตอนตั้งค่า (ครั้งเดียว)

1. สมัครและสร้างโปรเจกต์ใหม่ที่ supabase.com
2. เปิด **SQL Editor** → วางเนื้อหาไฟล์ [`supabase/schema.sql`](supabase/schema.sql) ทั้งหมด → กด **Run**
3. ไปที่ **Authentication → Sign In / Providers → Email** แล้ว **ปิด "Confirm email"**
   (ผู้เล่นสมัครด้วยชื่อผู้ใช้ ระบบสร้างอีเมลภายในให้เอง จึงยืนยันอีเมลไม่ได้)
4. ไปที่ **Project Settings → API** คัดลอก **Project URL** และ **anon public key**
   ใส่ใน [`js/online.config.js`](js/online.config.js):
   ```js
   window.ONLINE_CONFIG = { url: 'https://xxxx.supabase.co', anonKey: 'eyJ...', emailDomain: 'players.ragnarok-web.game' };
   ```
   (anon key เปิดเผยได้ ข้อมูลถูกป้องกันด้วย Row Level Security)
5. นำเกมขึ้นเว็บ เช่น **GitHub Pages** (Settings → Pages → เลือก branch), Netlify หรือ Vercel
   แล้วแชร์ลิงก์ให้เพื่อนสมัครเล่นได้เลย

### ความปลอดภัยและข้อจำกัด

- ผู้เล่นอ่าน/แก้ได้เฉพาะตัวละครของตัวเอง, ชื่อผู้ส่งแชทถูกกำหนดจากฝั่งเซิร์ฟเวอร์ (ปลอมชื่อไม่ได้), จำกัดแชท 1 ข้อความ/วินาที
- มอนสเตอร์และไอเทมยังคำนวณในเครื่องของแต่ละคน (ยังไม่ใช่มัลติเพลเยอร์เต็มรูปแบบ) และค่าในเซฟยังแก้ไขจากฝั่งผู้เล่นได้ — หากต้องการกันโกงจริงจังหรือตีมอนร่วมกัน/ปาร์ตี้ ต้องเพิ่มเซิร์ฟเวอร์เกมแบบ authoritative ในขั้นต่อไป

## ภาพและแอนิเมชัน (สร้างด้วย ChatGPT)

- ภาพนิ่ง (ไอคอน มอน NPC ฉาก แผนที่): prompt ใน [`art/PROMPTS.md`](art/PROMPTS.md) → ตัดด้วย `python3 tools/slice_sheet.py`
- **แอนิเมชันตัวละคร/มอน (มาตรฐาน NMS-1)**: รายการที่ต้องสั่งและ prompt อยู่ใน [`art/ANIM_PROMPTS.md`](art/ANIM_PROMPTS.md) ใช้เทมเพลต `art/tpl_*.png`
  - ติดตั้ง: `python3 tools/sprite_std.py install <ชีต.png> <key> <ท่า> --grid 4x5 --dirs S,SW,W,NW,N` — ตัดเฟรม ลบพื้น/เส้นไกด์ ปรับทุกเฟรมให้สูงเท่ากัน (150 px ในช่อง 240) สร้างทิศขวาจากการกลับด้าน
  - ตรวจก่อนส่ง: `tools/sprite_ruler.html` (Sprite Ruler) — วัดขนาด เตือนเฟรมเพี้ยน/ชนขอบ เล่นแอนิเมชันทีละทิศ
- `assets/manifest.json` มีรหัสเวอร์ชันของทุกภาพ (ภาพที่แก้ใหม่ชื่อเดิมจะไม่ติดแคช) — สร้างใหม่ด้วย `python3 tools/slice_sheet.py --manifest`
