การควบคุม

  • คลิกซ้าย ที่พื้น = เดิน (กดค้างเพื่อเดินตามเมาส์)
  • คลิกมอนสเตอร์ = โจมตีต่อเนื่องอัตโนมัติ
  • คลิกไอเทม บนพื้น = เก็บ • คลิก NPC = คุย
  • 1-8 = แถบสกิล • Z C V F = แถบไอเทม (ลากสกิล/ไอเทมมาวางได้) • Space = โจมตี/คุย/เก็บของ ที่ใกล้ที่สุด
  • A สถานะ • E ไอเทม • Q อุปกรณ์ • S สกิล • O ตั้งค่า • H วิธีเล่น
  • U ซ่อน/แสดง HUD ทั้งหมด • ปุ่ม ▾ มุมแผงเพื่อพับเก็บทีละแผง
  • X นั่งพัก • Enter แชท • Esc ปิดหน้าต่าง • ล้อเมาส์ / + − ซูม
  • B เปิด/ปิดบอท • N ตั้งค่าบอท • M แผนที่ใหญ่ (คลิกเพื่อเดินไปได้)
  • J เควสต์ — ภารกิจแนะนำทีละขั้น แตะแถบเควสต์ใต้การ์ดยูนิตเพื่อเดินไปทำทันที
  • G นำทาง — เลือก NPC / แผนที่ / มอนสเตอร์ แล้วตัวละครจะเดินไปเอง ข้ามแผนที่ได้ (คลิกชื่อบนแผนที่ใหญ่ก็ได้)
  • Tab เปิด/ปิดเมนู • ปุ่มลูกศร เดิน 8 ทิศ (กดสองปุ่มพร้อมกันเพื่อเดินแนวทแยง) • คลิกมินิแมพเพื่อเดินไปจุดนั้น

มือถือ / แท็บเล็ต

  • จอยซ้ายล่าง = เดิน 8 ทิศ • ปุ่มดาบขวาล่าง = โจมตีมอนที่ใกล้สุด / คุย NPC / เก็บของ
  • สกิลที่ต้องเลือกเป้า จะเล็งมอนที่ใกล้ที่สุดให้เอง • ปิด/เปิดปุ่มบนจอได้ใน ตั้งค่า
  • แตะ พื้นเพื่อเดิน, แตะมอนสเตอร์เพื่อโจมตี, แตะค้างเพื่อเดินตามนิ้ว
  • ถ่างสองนิ้ว เพื่อซูม • แตะค้างที่ปุ่มลัด เพื่อลบ • ใช้ปุ่ม 📌 ในหน้าต่างสกิล/ไอเทมเพื่อตั้งปุ่มลัด
  • จอยเกม: สติ๊กซ้ายเดิน • A โจมตี/คุย • B ยกเลิก/นั่ง • X Y LB RB = สกิล 1-4 • D-pad = สกิล 5-8 • LT RT L3 R3 = ไอเทม • Select แผนที่ • Start เมนู
  • ปุ่ม AUTO = ปล่อยบอทล่ามอน (ใช้ชุดซ่อม ใช้สกิล นั่งพัก เก็บของเอง) ทำงานต่อแม้สลับแอป สูงสุด 10 นาที

เส้นทางการเติบโต

  1. แจก Status Point (กด A) — STR สำหรับสายตี, INT สายเวท, DEX สายธนู, AGI ตีเร็ว/หลบ, VIT ถึก
  2. ออกไปทางตะวันออกของเมืองเพื่อล่า Gel Unit ใน Emerald Meadow
  3. เก็บ Job Lv 10 แล้วไปหา Mimir AI ในเมืองเพื่อ อัปเกรดร่าง เป็นคลาสใหม่
  4. 6 คลาสอัปเกรด: Einherjar, Rune Caster, Wildhunter, Völva, Loki's Trickster, Berserker
  5. ท้าทาย MVP: Seraph Core (Mistlake Plains) และ Kitsura EX (Hel's Hollow)
