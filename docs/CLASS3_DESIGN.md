### ✅ แนะนำ: **A+ = A + "Oath" 2 แบบต่อ Class**
- **Oath = รูนของสกิลติดตัว (Passive) ของ Class 3** → ใช้ระบบ Rune Paths ที่มีอยู่แล้วทั้งหมด (Class 1 ก็มีรูนบนสกิลติดตัว เช่น `iron_body`, `rune_mastery`) ไม่ต้องสร้างระบบใหม่
- เปลี่ยน Oath ได้ **ฟรีทุกที่นอกการต่อสู้** (กติกา 5 วิ เดียวกับรูน) = ได้ความหลากหลายแบบ C (24 สไตล์) **โดยไม่ล็อกถาวร** และ **ไม่เพิ่มภาพ**
- Echo skill ของ B เก็บไว้เป็นของเสริมทีหลังได้ (ดูคำถามข้อ 6)
- ภาพเท่า Class 2 (24 โมเดล) — คุมงบภาพได้

## 2. การปลด + เนื้อเรื่อง (ภาค 2)

### กติกาโลกที่ต้องเคารพ
- **ไม่มีใครเกิดใหม่** → Class 3 **ไม่ใช่ rebirth แบบ RO** (ไม่รีเซ็ต Base Lv ไม่กลับเป็น Novice) ผู้เล่นแค่ "ปลดชั้นที่สามของแม่พิมพ์"
- แม่พิมพ์ = ท่าของหกวีรชนบนกำแพงคืน Ragnarök (STORY §6) • Class 2 = "ชั้นที่สองที่ซ่อนอยู่สองทาง" ที่ Mimir ถอดรหัส
- ห้ามเติม **สองกิ่งที่เว้นว่าง** ของ Yggdrasil • ห้ามเติม **ท่อนที่หก** ของ Bragi (ว่างตลอดไป) • Loki ไม่ยอมรับตรง ๆ ว่าฝากแม่พิมพ์ Trickster

### แนวคิดเรื่อง: "ความคิดสุดท้ายของวีรชน"
- Class 1 = ท่า, Class 2 = ชั้นซ่อนของท่า, **Class 3 = สิ่งที่วีรชนคนนั้น "คิด" ตอนรุ่งเช้าก่อนล้ม** — Mimir เก็บได้แค่ *ความจำ* (Muninn) ส่วน *ความคิด* ถูก **Huginn** พาบินขึ้นเหนือไปแล้วไม่กลับ (STORY World Pack: "ความคิดไปไกลกว่าความจำเสมอ")
- **Hook ภาค 2 ข้อ (1):** ต้นไม้งอกประกายใหม่ที่ปลายกิ่งที่หักทางเหนือ → Huginn บินกลับมาจากทางนั้นพร้อม "เศษความคิดหกชิ้น" → Mimir ถอดรหัสชั้นที่สามได้ — แต่ต้องให้ผู้เล่น **"เดินตามความคิดนั้นให้ครบ"** ก่อน (= เควสต์ทดสอบ)
- **Hook ข้อ (2)** (Fenrir หอนพร้อมกัน / หัว Nidhogg ยังไม่ดับ) ใช้เป็นแรงผลักของบทแรกภาค 2 และผูกกับ Fenrir Packlord / Fimbul Huntmaster

## 3. Class 3 ทั้ง 12 ตัว

> รูปแบบ: ★ = สกิลประจำตัว (signature) • ชนิด: **P** ติดตัว • **AoE** หมู่ • **เดี่ยว** • **ซัพ** บัฟ/ฮีล/ปาร์ตี้ • **โซน** วางพื้น • **ไว** เคลื่อนที่
> **ULT** = ตัวเลือกที่ 4 ในปุ่ม ULT (เคียง BERSERK FURY / VALKYRIE AEGIS / WAR CRY) — **เป็นบัฟ/โหมด ไม่ใช่ระเบิดใหญ่** (เจ้าของถอดไม้ตายโจมตีแล้ว 2026-10-02) และค่าพอ ๆ กับ 3 ตัวเดิม
> **Oath** = รูน 2 แบบของสกิล P (keystone) • ทุกตัวมี 6 สกิล = **P 1 + Active 5** • ภาพ: Meshy ห้ามของลอย/เอฟเฟกต์ → อาวุธต้องติดมือ ไม่บังตัว ผ้าคลุมสั้นแข็ง
> id ข้อมูลที่เสนอ (ใหม่ทั้งหมด ไม่ชนของเดิม): `warden jarl runelord hexer huntmaster deadeye lifeweaver oathfist sixth warsinger packlord worldbreaker` • ทุกตัว `parent: <Class 2>`, `tier: 3`

### 3.1 Heimdall Warden — ผู้คุมสะพานแห่งไฮม์ดัล (`warden` ← Valkyrie Knight)
- **บทบาท:** แทงค์คุมพื้นที่ — ขีดเส้นที่ศัตรูข้ามไม่ได้ และรับแทนเพื่อนจริง ๆ
- **อาวุธ:** ดาบสั้นทอง + **โล่ทรงสูงสี่เหลี่ยม** ขอบสายรุ้ง (แขนซ้าย) • **ภาพ:** ขาว-ทอง + ขอบปริซึมรุ้ง • หมวกเขาแตรสูง, โล่สูงเกือบเท่าตัว, ไหล่หนา

| สกิล | ชนิด | ผล |
|---|---|---|
| Watchful Eye | P | DEF/MDEF+ • ศัตรูที่ตีเพื่อน/ตัวเราในระยะ 6 ติดรอย "ถูกจ้อง" รับดาเมจจากเรา +% |
| ★ Bifrost Line | โซน/AoE | ขีดเส้นรุ้งยาว 6 ช่อง 6 วิ ศัตรูที่เดินข้ามโดนดาเมจศักดิ์สิทธิ์ + ช้า • คนยืนบนเส้น DEF+ |
| Gjallar Call | ซัพ | ดึงศัตรูรอบ 8 ช่อง + ตัวเรา/ปาร์ตี้รับดาเมจ −15% 8 วิ (ส่งผ่านช่องปาร์ตี้แบบ WAR CRY) |
| Rainbow Bash | เดี่ยว | ฟาดโล่ 400–650% ศักดิ์สิทธิ์ มึน 1 วิ |
| Warden's Stand | ซัพ (ตัวเอง) | ยืนนิ่ง 5 วิ รับดาเมจ −40% สะท้อน 30% (ขยับ = ยกเลิก) |
| Guardian Leap | ไว/AoE | กระโดดไปหาเพื่อน/จุด ≤6 ช่อง กระแทกรอบ 2 ช่อง |

- **ULT GJALLARHORN:** 6 วิ ตัวเรา+ปาร์ตี้ระยะ 8 ไม่ล้ม (HP ต่ำสุด 1) + ดึง aggro ทั้งหมดมาที่เรา
- **Oath:** *of the Bridge* — 20% ดาเมจที่เพื่อนรับโอนมาหาเรา / *of the Horn* — ดาเมจที่กันได้สะสมเป็นพลัง ปล่อยใน Rainbow Bash (สายตีโต้)
- **ต่างจาก Valkyrie:** Valkyrie ยืนรับเอง + แผ่นดินไหว → Warden "จัดสนาม" ด้วยเส้น/การกระโดด และปกป้องคนอื่น
- **รูน Bifrost Line:** *Prism Wall* — เส้นเป็นกำแพง มอนเดินผ่านไม่ได้ 3 วิ (ไม่มีดาเมจ) / *Rainbow Ring* — วงรอบตัวรัศมี 3 แทนเส้น

**กับ Passive (แบบ D: เพดานรวม ATK/MATK จากต้นไม้ ≤25%)**
- ต้นไม้ไม่เปลี่ยน (ยัง 1 แต้ม/เลเวล ถึง 99) • Class 3 **ไม่เพิ่มโหนด** — ถ้าต้องการ ทำทีหลังเป็น "Notable มีเงื่อนไข" ตามแบบ C
- สกิล P ของ Class 3 **ห้าม +% ATK/MATK ถาวรเกิน +10%** (Lv 5) — เน้นผลมีเงื่อนไข (ศัตรูรอบตัว, ระยะ, คอมโบ, ยืนนิ่ง)
- งบ % ดาเมจถาวรรวม (Class bonus + สกิล P ทุกสาย + ต้นไม้) ตั้งเป้า **≤ +60%** ที่ Lv 99 (ตอนนี้ Lv 60 สายตีบางตัว +80% จากต้นไม้อย่างเดียว — แบบ D ต้องเข้าก่อน)

**กับรูน (แถบ ±12% — Claude ตัดสินแล้ว 2026-10-03)**
- ทุกรูนของ Class 3 และทุก Oath: ห่างจาก "ไม่มีรูน" **≤ ±12%** ในฉากที่ตั้งใจ (ฝูง/เดี่ยว) และ **≤ +15%** ทุกฉาก — จำลองด้วย `tests/runes.js`
- Oath ที่แลก DPS กับการอยู่รอด/ซัพ (Bridge, Release, of the Well) วัดด้วย "เวลาฆ่า + จำนวนครั้งที่ล้ม" ไม่ใช่ DPS อย่างเดียว

**กับ Hunt Rune (เพดาน +45%/ครั้ง)**
- เงื่อนไขในสกิล Class 3 ที่ **ซ้ำกับ Hunt Rune** (HP ศัตรูต่ำ = Executioner เช่น Norn Cut • ด้านหลัง = Ambusher เช่น Unmasked • ฝูง = Pack Breaker เช่น Pack Blood) → **นับรวมในเพดาน +45%** กันคูณซ้อน

**กติกาเดียวทุกที่ (PvE = PvP)**
- CC ทุกตัวมีค่า "บอส/ผู้เล่น" สั้นลงในตัว (≤1 วิ) — ไม่ทำตัวเลขแยกลานประลอง • ULT ใช้ได้ในลานเหมือนเดิม • ทดสอบ `tests/mp_pvp.js`

**สกิลปาร์ตี้ต้องมีค่ากับคนเล่นคนเดียว** — ทุกสกิลซัพเลือกตัวเองได้ และทุก Class ที่เน้นทีม (Warden / Lifeweaver / Warsinger) มี Oath สายเดี่ยว 1 แบบ
