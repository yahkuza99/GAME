# Paperdoll — เปลี่ยนอาวุธ/ใส่หมวกบนภาพเคลื่อนไหวทีละเฟรม (ทดลอง)

แนวคิดแบบ RO: ภาพตัวละคร **ไม่มีอาวุธ/หมวกติดมา** แล้วเกมวาดของที่สวมจริงทับในแต่ละเฟรม

## ทำงานยังไง

1. `python3 tools/paperdoll.py novice_f novice_m [--debug <โฟลเดอร์>]`
   - ลบใบมีดสีฟ้าออกจาก `anim_<key>_<ท่า>.webp` ทุกเฟรม (ส่วนที่ทับตัวเติมสีจากรอบข้าง)
   - เก็บ **หน้ากาก/ครีบหู** (สีฟ้าบนหัว), **วงเวท** (ท่าร่าย) และ **เส้นฟัน** (ท่าตี) ไว้
   - วัด **จุดมือ + มุมใบมีด** และ **ยอดหัว** ทุกเฟรมทุกทิศ
   - ได้ `assets/anim_<key>_bare_<ท่า>.webp` + `js/paperdoll_data.js`
2. เกม (`js/paperdoll.js`): ถ้ามีภาพ bare → วาดตัวเปล่า แล้ววาด **ไอคอนอาวุธที่สวม** ในมือ
   (หมุนตามมุมของเฟรม, วาดมือทับด้ามให้ดูเหมือนกำไว้, หันหลัง = อาวุธอยู่หลังตัว) และ **ไอคอนหมวก** ที่หัว
   - เฟรมเส้นฟัน = ซ่อนอาวุธ (เป็นเฟรมเบลอแทน)
   - ปิดทั้งระบบ: `Paperdoll.ON = false` → กลับไปใช้ภาพเดิมที่มีมีดติดมือ
3. จูนได้ใน `js/paperdoll.js`: ความยาว/จุดจับอาวุธต่อชนิด (`W`), ขนาด/ตำแหน่งหมวก (`HAT`), ระยะหมวกต่อตัวละคร (`HEAD_DY`)

## ผลทดลอง (Novice ชาย/หญิง)

- **อาวุธ: ใช้ได้ดี** — มีด ดาบ ขวาน กระบอง คทา ธนู ถือในมือได้ทุกทิศ ทุกท่า (เดิน ยืน ตี ร่าย นั่ง)
- **หมวก: ใช้ได้แค่ระดับทดลอง** — ไอคอนหมวกเป็นภาพมุมหน้ามุมเดียว ตอนหันหลังยังเห็นหน้าหมวก
  → ถ้าจะใช้จริงควรมีภาพหมวกแยก 3 มุม (หน้า / ข้าง / หลัง) ต่อชิ้น

## สำหรับ Class 2 (ถ้าจะใช้ระบบนี้)

- สั่งภาพท่าเดิน/ตี **ไม่ถืออาวุธ มือกำหลวม ๆ** และ **ไม่ใส่หมวก** → ไม่ต้องลบอะไร วัดแค่จุดมือ
  (หรือถือ "แท่งสีเขียวสด" เป็นตัวบอกตำแหน่ง/มุมมือ แล้วให้เครื่องมือลบออก — แม่นกว่า)
- ไอคอนอาวุธทุกชิ้นวาดเฉียง ด้ามซ้ายล่าง ปลายขวาบน — ภาพอาวุธใหม่ต้องวาดแบบเดียวกัน
