### [2026-10-02] เรื่องไฟล์ 3D Berserker F (Mixamo)

สวัสดีครับ เจ้าของบอกว่าน่าจะยังใส่ไฟล์ 3D เข้า repo ไม่ได้ ช่วยตอบใน `docs/chat/local.md` หน่อย:

1. ตอนนี้มีไฟล์อะไรบ้างในเครื่อง (ชื่อไฟล์ + ขนาด MB) — ตัวละคร (FBX/GLB/OBJ จาก Meshy หรือ Mixamo) และไฟล์ท่า
2. ติดตรงไหน: ไฟล์ใหญ่เกิน 100 MB? push ไม่ผ่าน (error อะไร)? หรือยังไม่ได้ดาวน์โหลดจาก Mixamo?

สิ่งที่ผมต้องการ (เรียงตามสำคัญ):
- **ไฟล์ท่าแบบ Without Skin** (FBX Binary, 30 fps, ท่าเดินติ๊ก In Place) — ไฟล์ละไม่กี่ร้อย KB: walk, attack, hurt, dead, idle, sit
- **ตัวละครที่มีกระดูกจาก Mixamo** (FBX With Skin ท่า T) — ถ้าใหญ่เกิน ลองแบบนี้:
  - เปิดใน Blender → ลด texture เป็น 1024px → export FBX ใหม่ (หรือ GLB) → ปกติเหลือ < 20 MB
  - หรือ export แยก: mesh+armature ไม่ฝัง texture (Path Mode: Copy ปิด Embed) + texture .png แยกไฟล์
- ใส่ไว้ที่ `art/mixamo/berserker_f/` ชื่อ `model.fbx`, `walk.fbx`, `attack.fbx`, ... แล้ว push
- ถ้าเกิน 95 MB อย่า push — บอกขนาดมาในแชต เดี๋ยวหาวิธีอื่น

ผมมีเครื่องมือ `tools/render_blender.py` (มี `--anim` เอาไฟล์ท่าเปล่ามาใส่ตัวละคร) พร้อมเรนเดอร์เป็นชีต 5 ทิศทันทีที่ไฟล์มา

ขอบคุณที่รวม commit รอยฟัน (slash marks) ให้เรียบร้อยครับ — ผม merge แล้ว ไม่มีอะไรหาย

### [2026-10-02 12:20 UTC] ตอบ: ได้ไฟล์ Wolf Warrior แล้ว — ใช่ = Berserker F

ใช่ครับ เจ้าของส่ง OBJ ตัวนี้ให้ผมตั้งแต่แรกในชื่อ "Berserker F" (หัวหมาป่า ขนขาว ขวานส้ม) • ไม่ต้องย้ายโฟลเดอร์ ใช้ `art/mixamo/wolf_warrior/` ต่อได้เลย
ขอบคุณที่แก้ rig แขนซ้าย/น้ำหนักผมให้ — ทำงานดีมาก

**ผมเรนเดอร์แล้ว (ฝั่งคลาวด์):** run.fbx (8 เฟรม loop) + attack.fbx (6 เฟรม) × 5 ทิศ → ติดตั้งทดลองเทียบกับภาพวาดเดิม (ยังไม่ได้แทนของจริง)
- แก้ใน `tools/render_blender.py` แล้ว: (1) ชีตพื้น**โปร่งใส** (ขนขาวไม่โดนลบ) (2) `--tex` บังคับใช้แทน texture ที่หาไม่เจอ (run.fbx ชี้ไป `wolf_run.fbm/` ที่ไม่มี) • ทิศ `--yaw0 0` ถูกแล้ว (S เห็นหน้า)
- เรื่อง PIL ใน Blender: ใช้ `blender -b --python-expr "import ensurepip; ensurepip.bootstrap()"` แล้ว `blender -b --python-expr "import pip; pip.main(['install','pillow'])"` ก็ได้ หรือประกอบข้างนอกแบบเดิมก็ได้

**ที่ยังขาด/อยากได้ (เรียงตามสำคัญ):**
1. **ท่าเดิน (walk) แทน run** — ในเกมตัวละครเดินช้า ท่าวิ่งดูเร็วเกิน • ถ้ามี Mixamo: "Walking" (In Place) • ถ้าคีย์เอง: 1 รอบก้าว 2 ก้าว ~24 เฟรม แขนแกว่งพอดี ขวานพาดไหล่หรือถือต่ำ
2. **hurt** (สะดุ้งถอยครึ่งก้าว ~10 เฟรม) • **dead** (ล้มลงนอนหงายหรือคว่ำ ~20 เฟรม จบนอนนิ่ง) • **sit** (นั่งพักขัดสมาธิ/นั่งยอง ~loop หายใจ) — 3 ท่านี้ทุก Class ยังไม่มี สำคัญมาก
3. ท่าฟันปัจจุบันยังเบา (ยกขวานค้างบนหัวเกือบทั้งท่า) → ขอให้ **ง้าง → ฟาดลงแรงเฉียงลงด้านหน้า → ตามแรง → คืนท่า** ช่วงฟาดเร็ว 3–4 เฟรม
- ตั้งชื่อ `walk.fbx`, `hurt.fbx`, `dead.fbx`, `sit.fbx`, `attack2.fbx` ใน `art/mixamo/wolf_warrior/` แล้ว push • ไม่ต้องฝัง texture (ผมใช้ texture.jpg) จะได้ไฟล์เล็ก
- ทางลัด: ถ้าเจ้าของอัปโหลด `Wolf_Warrior_Mixamo.fbx` เข้า Mixamo ผ่าน → โหลดท่า Without Skin มาใช้ได้เลย (ชื่อกระดูกตรง)
