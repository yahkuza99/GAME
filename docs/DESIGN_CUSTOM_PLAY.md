# IRON VALHALLA — Custom Play (เสาหลักของเกม)

> เป้าหมายเจ้าของ (2026-10-03): **"เป็นผู้นำด้านเกมแบบ custom play"**
> แปลเป็นหลักออกแบบ: *ผู้เล่น 2 คนที่ Class เดียวกัน เลเวลเท่ากัน ต้องเล่นต่างกันได้จริง และทั้งคู่เก่งได้*

> **ปรัชญาเจ้าของ (2026-10-03): "อิสระเป็นของผู้เล่น"** → ทุกการตัดสินใจด้านล่างเอียงไปทางให้ผู้เล่นเลือกเอง ไม่ล็อก ไม่บังคับ
> - **ไม่ล็อกเซ็ตตาม Class** — ใครสวมก็ได้ โบนัส 2–3 ชิ้นใช้ได้ทุกคน • 4-pc twist ผูกกับสกิล จึงทำงานเฉพาะคนที่มีสกิลนั้นเอง (ล็อกตามธรรมชาติ ไม่ใช่ห้ามสวม)
> - **เปลี่ยนรูนได้ทุกที่ฟรี** (นอกการต่อสู้ 5 วิ) • รีเซ็ต Passive ราคาถูก
> - **AUTO เป็นเครื่องมือ ไม่ใช่ข้อบังคับ** — ปิด/เขียนกฎเอง/ใช้ค่าเริ่มต้น ได้หมด
> - **HUD ย้ายได้** • ไม่มีทางเลือกที่ "ถูก" ทางเดียว

## หลัก 4 ข้อ
1. **เลือกแล้วเปลี่ยนวิธีเล่น ไม่ใช่แค่ +%** — ทุกตัวเลือกต้องเห็นผลบนจอ (สกิลแตก, ทิ้งพื้นไฟ, ดึงมอน ฯลฯ)
2. **Sidegrade ไม่ใช่ upgrade** — ตัวเลือกในชั้นเดียวกันแรงพอ ๆ กัน (เช็กด้วยการจำลอง DPS ให้ห่างกัน ≤ ±5% ใน tests แบบ keystone balance)
3. **ลองได้ไม่เจ็บ** — รีเซ็ตฟรีในเมือง, เก็บ build ได้หลายชุด
4. **แชร์ได้** — build / สคริปต์ AUTO ส่งเป็นโค้ดสั้น ๆ ให้เพื่อนได้ → ชุมชนแข่งกันคิด build = จุดที่ทำให้ "เป็นผู้นำ"

## ระบบ (เรียงตามผลกระทบ)

### 1. Rune Paths — ปรับแต่งสกิล (หัวใจ)
- ทุกสกิลมี **3 ชั้น** ชั้นละ **เลือก 1 จาก 2–3 รูน**
  - ชั้น I ปลดที่ Skill Lv 4 • ชั้น II ที่ Lv 7 • ชั้น III ที่ Lv 10 + Mastery (ต่อยอดระบบ mastery ที่มีอยู่)
- ตัวอย่าง (Runecaster — FIREBALL)
  - I: *Split* แตก 3 ลูก (ดาเมจลูกละ 45%) / *Heavy* ลูกเดียวใหญ่ +60% รัศมีระเบิด
  - II: *Cinder* ทิ้งพื้นไฟ 3 วิ / *Kindle* ศัตรูติดไฟ = สกิลถัดไปคริติคอลแน่นอน
  - III: *Meteor* เปลี่ยนเป็นลูกตกจากฟ้า (ดีเลย์ 0.6 วิ ×2.2) / *Chain* กระโดดไปอีก 2 ตัว
- เปลี่ยนได้ทุกที่ฟรี (นอกการต่อสู้) • ไม่เปลี่ยน id สกิลเดิม (เพิ่มฟิลด์ `runes` ในเซฟ)

### 2. Battle Script — โปรแกรม AUTO เอง (จุดต่างที่เกมอื่นไม่มี)
- บอท AUTO ปัจจุบัน (js/bot.js) ตั้งได้แค่ใช้สกิลไหน/พักเมื่อไร → ยกระดับเป็น **กฎ IF → THEN เรียงลำดับ** (แนว Gambit ของ FF12)
  - เงื่อนไข: HP/SP ตัวเอง < X% • เป้าเป็นบอส/MVP • มอนรอบตัว ≥ N • เพื่อนปาร์ตี้ HP < X% • บัฟ X หมด • เป้าธาตุ X • ดีบัฟบนเป้า
  - การกระทำ: ใช้สกิล X (+รูน) • ดื่มยา • ถอยห่าง • เปลี่ยนเป้า (ตัวใกล้สุด/HP ต่ำสุด/ตัวที่ตีเพื่อน) • นั่งพัก
- ค่าเริ่มต้น = กฎที่ให้ผลเหมือนบอทตอนนี้ทุกอย่าง (ผู้เล่นเดิมไม่รู้สึกต่าง)
- แชร์เป็นโค้ด (`IV-SCRIPT:...`) • จำกัด 12 กฎ (กันเครื่องช้า) • ทดสอบด้วย tests/bot_ai

### 3. Loadouts + Build Code
- เก็บ **3 ชุด**: Passive + Rune Paths + อุปกรณ์ + แถบลัด + Battle Script → สลับคลิกเดียว (นอกการต่อสู้)
- ปุ่ม "คัดลอก Build" → โค้ดสั้น วางในแชต/เว็บ Codex เปิดดูได้ (หน้า Build ใน Valhalla Codex)

### 4. Sets / Chips / Passive (ต่อจาก docs/DESIGN_SETS_CHIPS_PASSIVE.md)
- **4-pc set twist = รูนพิเศษ** ที่หาได้จากของเท่านั้น (ใช้กลไกเดียวกับ Rune Paths → โค้ดน้อยลง)
- Chips มีเงื่อนไข + โบนัสเฉพาะ Class (ตามแบบเดิม)
- **Passive: แนะนำตัวเลือก C** (เปลี่ยนโหนดเป็นผลแบบมีเงื่อนไข) เพราะเข้ากับ custom play ที่สุด • ทำ A (ลด % ครึ่ง) ไปก่อนเพื่อแก้ "เก่งเกิน" ทันที แล้วค่อยเปลี่ยนเป็น C

### 5. HUD ปรับเองได้ (รวมใน UI redesign เฟส 2)
- ย้าย/ย่อขยาย แถบลัด มินิแมพ ปุ่มโจมตี • เลือกปุ่มเมนูที่โชว์ • จำต่อตัวละคร

### 6. ภายหลัง
- ห้อง PvP กฎกำหนดเอง (ห้ามยา / เลเวลเท่ากัน / Class เดียว) • ย้อมสี / transmog
