## 3. ชิป: เซ็ตชิป • ชิปมีเงื่อนไข • ชิปเฉพาะ Class

**3.1 ระบบใหม่ที่ต้องเพิ่มในเกม (ทำครั้งเดียวใช้กับทุกอย่าง):**
- ดาเมจตามเผ่า (`race`: พืช แมลง สัตว์ อันเดด เทวะ ปีศาจ ไร้รูป) — มอนมีเผ่าอยู่แล้วแต่ยังไม่มีผล
- ต้านธาตุ (ไฟ น้ำ ลม ดิน ศักดิ์สิทธิ์ มืด)
- ตัวปรับรายสกิล (ดาเมจ / คูลดาวน์ / SP / วง / ลูกเล่น) — ใช้ร่วมกับเซ็ตข้อ 1–2
- เงื่อนไข (trigger): HP ต่ำกว่า X • ตอนโดนตี • ตอนฆ่า • ตอนใช้สกิล • ตอนอยู่แมพมืด/ถ้ำ • ตอนอยู่ในปาร์ตี้

**3.2 ชิปมีเงื่อนไข (ตัวอย่าง ใช้กับชิปเดิมโดยเพิ่มผลรอง — ไม่เปลี่ยน id):**

| ชิป | ผลเดิม | + เงื่อนไขใหม่ |
|---|---|---|
| Draugr Husk (โล่) | HP+200 | HP ต่ำกว่า 30% → DEF +10 นาน 5 วิ (ครั้งละ 20 วิ) |
| Fenrir Unit (อาวุธ) | CRI+8 | คริติคอลแล้ว 10% ได้ ATK +10% 4 วิ |
| Hel Maiden (หัว) | INT+1 MDEF+5 | ดาเมจต่อ **อันเดด** +15% |
| Ash Stalker (ผ้าคลุม) | AGI+2 FLEE+3 | หลบได้แล้ว ตีครั้งถัดไป +30% |
| Rust Sap (ชุด) | HP+300 LUK+1 | ฆ่ามอนแล้วฟื้น HP 1% |
| Root Gnawer (เครื่องประดับ) | STR+2 ATK+8 | ดาเมจต่อ **พืช** +15% |

**3.3 ชิปเฉพาะ Class:** ชิปใบเดิมได้ "ผลพิเศษ" เพิ่มถ้าผู้ใส่เป็น Class ที่ตรง เช่น Fenrir Unit + Trickster = Backstab +10% • Kitsura EX + Runecaster = Fire Rune เป็นวง • Garmr + Berserker = เลือดดูด +2%

**3.4 เซ็ตชิป (ใส่ชิปจากแมพเดียวกันครบ):**

| เซ็ตชิป | ชิปที่ต้องใส่ | โบนัส |
|---|---|---|
| ลมหายใจทุ่งหญ้า | Gel Unit + Bunny Unit + Ember Unit | ฟื้น HP/SP ตอนนั่ง +30% |
| ฝูงหมาป่า | Fenrir Unit + Ash Stalker + Tusk Trooper | ดาเมจต่อ **สัตว์** +12% |
| ราชสำนักเฮล | Hel Maiden + Hel Guard + Draugr Husk | ต้าน**มืด** +20% • ดาเมจต่อ **อันเดด** +10% |
| ความรู้ต้องห้าม | Archive Maiden + Archive Warden + Rust Mine | ร่ายเร็ว +8% • SP ใช้ −8% |
| รากที่ถูกแทะ | Root Gnawer + Root Crawler + Gnawed Brute | HP +8% • ดาเมจต่อ **พืช** +10% |

**ระวังเศรษฐกิจ/เลเวล:** ชิปยังได้แบบเดิม (ล่าครบ 50 ตัวได้แน่นอน) • ไม่มีโบนัส EXP/เงินจากชิป (เคยตกลงเรื่องเก็บเลเวลช้า)

## 4. Passive — ปรับให้ "เลือกทางเล่น" แทน "บวกเลขมหาศาล"

> ✓ **ทำแล้ว 2026-10-03 แบบ D** (เจ้าของ "ทำเลย"): ตัวเลขเล็กลง + เพดานรวมจากต้นไม้ (`PCAP` ใน js/passive.js) + Notable/Keystone เป็นลูกเล่นมีเงื่อนไข + รีเซ็ตฟรี 1 ครั้งให้เซฟเก่า • จำลอง tests/passive.js: Lv 99 เต็มต้น ≈ +30% (เดิม +131%) • ตารางเพดาน/โหนดทั้งหมดอยู่ใน docs/GAME_REFERENCE.md หัวข้อ Passive และแท็บ Passive ใน Valhalla Codex

**ปัญหาเป็นตัวเลข:** Lv 60 Berserker ได้ ATK +80% จากต้นไม้อย่างเดียว • Hunt critDmg +39% • Rune MATK +34% + ร่ายเร็ว 22%

**ข้อเสนอ (เลือกได้ 3 ระดับ):**

| ทาง | ทำอะไร | ผล |
|---|---|---|
| **A. ลดตัวเลข (เบาสุด)** | โหนดเล็ก % ลดครึ่ง (ATK 4%→2%) • โหนดเด่น 10–12% → 6% • Keystone คงเอกลักษณ์แต่ลดครึ่ง (Overclock ATK +40% → +20% / HP −25% คงเดิม) | Lv 60 สายตี ATK ~+35% • แก้เร็ว ไม่ต้องคิดใหม่ |
| **B. ลดตัวเลข + ลดแต้ม** | A + แต้มเป็น 1 แต้ม/2 เลเวล หลัง Lv 30 (Lv 60 = 44 แต้ม) | เลือกยากขึ้น ต้องวางแผน |
| **C. ออกแบบใหม่ (แนะนำระยะยาว)** | โหนดเด่นเปลี่ยนจาก "+% เฉย ๆ" เป็น **ลูกเล่นมีเงื่อนไข** เช่น "หลบได้แล้วตีแรงขึ้น", "ใช้สกิลติดกัน 3 ครั้งลด SP", "อยู่ใกล้ศัตรู 3 ตัวขึ้นไป DEF +" • โหนดเล็กเหลือค่าเล็ก ๆ | ต้นไม้เป็นตัวกำหนดสไตล์ ไม่ใช่แหล่งพลังหลัก • งานเยอะสุด |

**เรื่องเซฟ:** id โหนดคงเดิม เปลี่ยนแค่ค่า → เซฟเก่าใช้ได้ • ให้ **รีเซ็ตแต้มฟรี 1 ครั้ง** ตอนปรับ
