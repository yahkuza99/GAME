# tools/char3d — โมเดล 3D (Meshy) → 7 ท่าสำหรับชีต Class

ทำครั้งแรกกับ Wolf Warrior = Berserker F (2026-10-02) · ผลอยู่ที่ `art/mixamo/wolf_warrior/`
ต้องมี Blender 4.4+ (ทดสอบบน 5.2) · ทุกสคริปต์รันแบบ `blender -b --factory-startup -P <สคริปต์> -- <อาร์กิวเมนต์>`

## ขั้นตอน (ต่อ 1 ตัวละคร)

1. **ตรวจ rig** — `inspect_rig.py <meshy.fbx> <out_prefix> [--tex texture.png]`
   ได้ภาพกระดูกทับเนื้อ หน้า/ข้าง + ตำแหน่งกระดูกทุกตัว · ดูว่าแขน/ขาอยู่ในแขน/ขาจริงไหม
2. **แก้ rig (ถ้าเพี้ยน)** — `fix_rig.py <meshy.fbx> <fix.json> <rig.blend>`
   ใส่ตำแหน่งกระดูกใหม่ (พิกัดโลก) ใน JSON → ย้ายกระดูก → คำนวณน้ำหนักใหม่ทั้งตัว → บังคับผม/ผ้าคลุมหลังให้ตามหัว/หลัง
   ตัวอย่าง: `examples/wolf_warrior_fix.json` · ถ้า rig ถูกอยู่แล้วข้ามขั้นนี้ ใช้ไฟล์ .fbx ตรง ๆ ในขั้น 3
3. **คีย์ท่า** — `poses.py <rig.blend|rig.fbx> <outdir> --hand Right --pin "x<-0.52"`
   ได้ `walk / attack / skill / buff / hurt / dead / sit .fbx` (ไม่ฝัง texture → เรนเดอร์ด้วย `--tex`)
   - `--hand` มือถืออาวุธ (Left = กลับด้านทุกท่าให้เอง · ทดสอบแค่ว่าทำงาน ยังไม่เคยใช้กับตัวถือมือซ้ายจริง)
   - `--pin` ปักอาวุธติดมือ 100% (เงื่อนไขพิกัดโลกท่าตั้งต้น) — Meshy มักให้ปลายด้ามที่อยู่ใกล้ขาขยับตามขา
   - `--actions walk,attack` เลือกบางท่า · `--save x.blend` เก็บไฟล์ไว้แก้ต่อ
4. **ตรวจพื้น** — `ground_check.py a.fbx b.fbx …` → z ต่ำสุดต้อง ≈ 0 ทุกเฟรม (ยกเว้นช่วงกระโดดของ skill)
5. **เรนเดอร์ชีต** — `tools/render_blender.py` (ของเดิม) ใส่ `--tex texture.jpg --frame <ortho>,<centerZ>`
   buff/skill ใช้ `--pick` เลือกเฟรมเอง (Wolf: `--pick 1,4,7,10,13,17`) ไม่งั้นพลาดจังหวะทุบ

## ท่าที่ได้ (เลขเฟรม/มุมอยู่ในตารางใน poses.py — ปรับต่อตัวได้)

| ท่า | เฟรม | loop | จังหวะ |
|---|---|---|---|
| walk | 1–25 | ✓ | 2 ก้าว, แขนว่างแกว่งสวน, อาวุธถือต่ำ |
| attack | 1–22 | ✗ | ง้าง f1–6 → ฟาด f6→f9 → ตามแรง f9–16 → คืน f22 |
| skill | 1–22 | ✗ | ย่อ → กระโดด (ยอด 0.42 ม. f10) → ทุบพื้นหน้า f13 → ค้าง → คืน |
| buff | 1–20 | ✗ | ย่อ → ชูอาวุธตั้งตรงชี้ฟ้า + กำหมัด เงยหน้าคำราม (ค้าง f9–13) → คืน |
| hurt | 1–12 | ✗ | เอนหลัง 30° ถอยครึ่งก้าว → คืน |
| dead | 1–24 | ✗ | เซ → เข่าทรุด → ล้มหงาย → นอนนิ่งตั้งแต่ f21 |
| sit | 1–25 | ✓ | นั่งย่อ อาวุธพาดตัก หายใจ |

## บทเรียน (พลาดมาแล้ว)

- **Meshy วางกระดูกผิดได้** — Wolf Warrior: แขนซ้ายทั้งโซ่อยู่ในแผงผม, ผมผูกกับกระดูกแขน → วิ่งแล้วผมแกว่งแทนแขน · ตัว+ผม+อาวุธเป็น mesh ก้อนเดียว แยกชิ้นไม่ได้
  หาเส้นกลางแขนจริง: ตัดเนื้อเป็นชั้นตาม x แล้วหาค่ากลาง (y,z) ของจุดด้านหน้า (y<0) ช่วงความสูงไหล่
- **ท่าของ Meshy ใช้ไม่ได้หลังย้ายกระดูก** — ท่าถูกทำมาให้กระดูกตำแหน่งเดิม แขนจะงอพับแปลก → คีย์ใหม่เอง
- **วัดพื้นจากเนื้อจริง ไม่ใช่จากกระดูกเท้า** — ฝ่าเท้า/ด้ามอาวุธ/แผงผมจมพื้นได้ (นั่ง −28 ซม. · นอน −46 ซม.) → `ground_mesh()` ยกสะโพกทุกเฟรม
- **ยกแขนถืออาวุธขึ้นสูง อาวุธจะนอนขวาง** (หมุนตามแขน) → `upright` หมุนข้อมือกลับให้ด้ามตั้งตรง
- **ขาวจัดไม่เข้ากับภาพวาด** — ลดเฉพาะพิกเซลสว่าง+สีจาง ×0.82 อมครีม (`art/mixamo/wolf_warrior/texture.jpg`)
- **Blender ลบ action ที่ไม่มีผู้ใช้ตอนบันทึก** → `use_fake_user = True` (ไม่งั้นเปิด .blend มาเหลือท่าเดียว)
- **ห้ามตั้งชื่อสคริปต์ชนโมดูล Python** (`inspect.py` ในโฟลเดอร์ทำงานทำ numpy พัง)
- พิกัด: ตัวละครหันหน้า −Y · `Rx(+)` = เหวี่ยงไปหลัง · ทุกท่าหมุนในพิกัดโลกรอบข้อต่อ (`rot_about`) แล้วให้ Blender คิดกลับเป็น local
